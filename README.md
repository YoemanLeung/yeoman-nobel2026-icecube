# 冰立方 IceCube — an interactive by 星野旅人 Yeoman

How IceCube, a cubic kilometre of Antarctic ice, catches a neutrino and points back to where it came from: a guided
tour narrated by the cat Yeoman, made for the 2026 Nobel Prize in Physics.

- **Website:** https://yoemanleung.github.io/yeoman-nobel2026-icecube/
- **Film version** (no controls, for recording): https://yoemanleung.github.io/yeoman-nobel2026-icecube/film.html

A static site: no tracking, no cookies, no requests to other servers (fonts are self-hosted, so it also works in
mainland China). The page, its text and its narration are by 星野旅人 Yeoman (CosmicTraveler – Yeoman); the
background score is generated by code written for this piece. Facts and their sources are listed inside the page
(the "i" button).
